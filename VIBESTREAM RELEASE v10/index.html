VIBESTREAM RELEASE

Настольный музыкальный плеер на Python и PyQt6: безрамочный мини-плеер в правом нижнем углу при закрытии окна, непрерывный повтор одного трека (1x LOOP), прослушивание выбранного плейлиста, лайки, оценки 1–5 звёзд, синхронизированные тексты, 10-полосный эквалайзер и офлайн-кэш.

Скачать VIBESTREAM RELEASE.exe Скачать архив исходников (.ZIP)

Безрамочный мини-плеер

При закрытии главного окна появляется компактное окно в правом нижнем углу с таймером, секундами, перемоткой, лайком и переключением треков.

Плейлисты и повтор трека

Выберите плейлист и слушайте его треки, либо включите 1x LOOP, чтобы выбранная песня играла по кругу непрерывно.

Лайки, эквалайзер и тексты

Ставьте лайки в основном окне и в мини-плеере, оценивайте треки звёздами, смотрите тексты песен и настраивайте 10-полосный эквалайзер.

Как запустить или собрать

  1. Если рядом лежит dist/VIBESTREAM RELEASE.exe — нажмите кнопку скачивания выше и запустите файл.
  2. Для сборки .exe из исходников запустите BUILD_RELEASE.bat.
  3. Для быстрой отправки проекта в GitHub запустите PUBLISH_GITHUB.bat.
